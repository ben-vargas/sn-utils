# Contributing feedback

This repository is used for SN Utils Issues and Discussions. Current extension
source is not maintained here, and source-code pull requests are not accepted.

- Open an [Issue](https://github.com/arnoudkooi/SN-Utils/issues) for a
  reproducible bug. Include the extension version, clear reproduction steps,
  relevant diagnostic information, and screenshots where useful.
- Start a [Discussion](https://github.com/arnoudkooi/SN-Utils/discussions) for
  questions, feature ideas, and broader feedback.
- Follow the [Code of Conduct](./CODE_OF_CONDUCT.md) when participating.
- Report security issues privately according to [SECURITY.md](./SECURITY.md).

Product documentation is maintained at [snutils.com/docs](https://snutils.com/docs).
