# SN Utils

SN Utils is a browser extension that adds productivity tools for the ServiceNow
platform.

## Repository status

This repository is the public Issues and Discussions hub for SN Utils.

Current extension source is not maintained or published through this repository.
The historical v9 source was removed from the default branch because it no longer
represents the extension currently distributed through the browser stores.

## Free and Pro

SN Utils is the product. It is available with Free and Pro plans.

The Free plan provides the core SN Utils experience at no cost, including for
professional use. Pro adds advanced and connected capabilities such as Sidekick,
advanced Copy Mode, GraphQL Code Search, Snippets, custom commands and shortcuts,
AI, Cloud Sync, and Team Space.

## Feedback and support

- Use [Issues](https://github.com/arnoudkooi/SN-Utils/issues) for reproducible
  bugs. Include the SN Utils version and the diagnostic information available
  from the extension's About tab.
- Use [Discussions](https://github.com/arnoudkooi/SN-Utils/discussions) for
  questions, ideas, and general feedback.
- Report vulnerabilities privately as described in [SECURITY.md](./SECURITY.md).

This repository does not accept source-code pull requests.
